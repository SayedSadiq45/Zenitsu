# Zenitsu Aura

An immersive, single-page visual experience inspired by Zenitsu Agatsuma, built as a cinematic showcase for **SayedSadiq45**.

## Live Website

[zenitsu-aura-sayed-sadiq.vercel.app](https://zenitsu-aura-sayed-sadiq.vercel.app/)

## Highlights

- Three button-driven scenes: **The Fall**, **The Impact**, and **Awakening**
- Animated thunder, sparks, wind, clouds, particles, and screen shake
- Interactive split reveal controlled by mouse or touch movement
- Responsive layout with reduced-motion support
- Custom visual direction using gold lightning, blue aura, Japanese typography, and cinematic motion
- No build step required: the experience runs as a static HTML page

## Run Locally

Open `index.html` directly in a browser, or serve the folder with any static web server:

```powershell
python -m http.server 8000
```

Then visit [localhost:8000](http://localhost:8000).
